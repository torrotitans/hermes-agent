# Brand Design Directory

Complete listing of available design themes from getdesign.md with style profiles and recommended use cases.

## How to Use This Directory

1. **Browse** the categories to find brands that match your UI needs
2. **Visit** `https://getdesign.md/<brand>/design-md` for full design specifications
3. **Apply** the selected theme using the workflow in [`SKILL.md`](../SKILL.md)

## How to Choose

### For Developer-Facing Products
1. **Vercel** - Clean, professional, highly readable
2. **Linear** - Precise, engineer-focused, minimal
3. **Raycast** - Modern, productive, efficient

### For Consumer-Facing Products
1. **Notion** - Warm, approachable, content-friendly
2. **Stripe** - Trustworthy, professional, conversion-optimized
3. **Airtable** - Structured, friendly, accessible

### For Data-Intensive Dashboards
1. **PostHog** - Dense but readable, analytical
2. **Sentry** - Dark mode optimized, data-heavy
3. **Cohere** - Gradient depth, information hierarchy

### For Premium/Enterprise Feel
1. **Superhuman** - Luxurious, precise, keyboard-first
2. **Linear** - Engineering excellence, refined
3. **HashiCorp** - Corporate professional, trustworthy

## Adding a New Brand

To request a new brand design:
1. Visit https://getdesign.md/request
2. Submit the brand name and URL
3. Wait for the DESIGN.md to be created and published
