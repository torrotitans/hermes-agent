# Execution Plan: Layer 6 - AI SRE (Reliability & Gateway)

## System Context for 7B Model
**Role:** You are the execution agent tasked with building Layer 6 of the Torro Agent Architecture.
**Goal:** Implement the operational heartbeat monitoring, yaml-based entitlements, and intelligent load balancing (Cloud-Bursting).
**Invariants to Enforce:**

## Phase 1: Telemetry & Heartbeat Monitoring
**Token Estimate:** ~1M Tokens
**Objective:** Establish swarm performance tracking.

### Task 1.1: Heartbeat Ingestion
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/sre/telemetry.py` (new)
**Action Steps:**
1. Create `engine/sre/telemetry.py`.
2. Define `SREAgent` class with `FN:register_heartbeat`.
3. Implement a dictionary/in-memory cache that stores the `last_seen` timestamp for agent UUIDs.
4. Implement `FN:scan_dead_agents` to iterate the cache and flag any agent not seen in > 60 seconds as Offline.
**Acceptance Criteria:** The script successfully registers pings and accurately flags timed-out mock agents.

### Task 1.2: Token Velocity Tracking
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/sre/telemetry.py`
**Action Steps:**
1. Implement `FN:track_token_burn` in `SREAgent`.
2. Add logic to sum token usage per workflow ID.
3. If usage exceeds the assigned limit (1M for planning, 128k for task), throw a `TokenExhaustionError`.
**Acceptance Criteria:** The tracking logic accurately trips the limit exception when thresholds are breached.

## Phase 2: AI Gateway & Cloud-Bursting
**Token Estimate:** ~1M Tokens
**Objective:** Build the intelligent router evaluating YAML rules and routing LLM traffic.

### Task 2.1: Deterministic ABAC YAML Parser
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/sre/gateway.py` (new), `config.ini` (mock)
**Action Steps:**
1. Create `engine/sre/gateway.py`.
2. Create `entitlements.yaml` (mock) with a rule: `deny_cloud: /src/core/auth_keys.py`.
3. Define `AIGatewayRouter` class with `FN:evaluate_abac_rules`.
4. Parse the YAML and check if an incoming task payload contains the restricted path string.
**Acceptance Criteria:** `evaluate_abac_rules` returns `LOCAL_ONLY` if the restricted string is present, and `ALLOW_CLOUD` if not.

### Task 2.2: Load Balancer Tier Selection
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/sre/gateway.py`
**Action Steps:**
1. Implement `FN:route_task` in `AIGatewayRouter`.
2. Accept a task complexity score (1-10) and an ABAC status.
3. Logic: If ABAC == `LOCAL_ONLY`, route to `LOCAL_70B`.
4. Logic: If ABAC == `ALLOW_CLOUD` and complexity > 7, route to `VERTEX_AI` (Cloud-Burst).
5. Return the selected model endpoint string.
**Acceptance Criteria:** The routing algorithm correctly returns `LOCAL_70B` or `VERTEX_AI` based on the specified conditions.
