# Execution Plan: Layer 3 - Execution (Deterministic Factory Floor)

## System Context for 7B Model
**Role:** You are the execution agent tasked with building Layer 3 of the Torro Agent Architecture.
**Goal:** Implement the execution swarm (Coders, Testers, Security, DevOps) and the Zero-Trust Docker Sandboxing mechanism.
**Invariants to Enforce:** 
- Strict Least Privilege: No execution on host OS. All code execution runs in Docker.
- Code generated must adhere to Torro Principle 1 (Simplicity) and Principle 14 (FN: Tags).
- Any failing test must immediately trigger a Mistake Analysis hook (Fail-Fast).
- Use exact Python typings. No `any`.

---

## Phase 1: Zero-Trust Sandboxing & DevOps Gatekeeper
**Token Estimate:** ~1M Tokens
**Objective:** Establish the ephemeral Docker environment required for safe code execution and testing.

### Task 1.1: Docker Sandbox Provisioner
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** Python `subprocess` or `docker` SDK.
**Action Steps:**
1. Create `engine/execution/devops_gatekeeper.py`.
2. Define `DevOpsGatekeeper` class with `FN:provision_sandbox`.
3. Implement logic to spawn a lightweight Alpine or Ubuntu-based Docker container using `subprocess.run(["docker", "run", "-d", ...])`.
4. Return the container ID.
**Acceptance Criteria:** The function successfully creates an ephemeral Docker container and returns its hash string.

### Task 1.2: Sandbox Execution Engine
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/execution/devops_gatekeeper.py`
**Action Steps:**
1. Implement `FN:execute_in_sandbox` inside `DevOpsGatekeeper`.
2. Accept a container ID and a bash command string.
3. Use `docker exec` to run the command inside the container and capture stdout/stderr.
4. Implement `FN:destroy_sandbox` to immediately `docker rm -f` the container after execution.
**Acceptance Criteria:** The code successfully executes a safe command (`echo "test"`) inside the sandbox and destroys the container, leaving no orphaned processes.

## Phase 2: Agentic Validation Swarm (Security & Compliance)
**Token Estimate:** ~1M Tokens
**Objective:** Implement the mandatory validation agents that check code before test execution.

### Task 2.1: Security Agent Audit
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/execution/security_agent.py` (new)
**Action Steps:**
1. Create `engine/execution/security_agent.py`.
2. Define `SecurityAgent` class with `FN:scan_payload`.
3. Implement regex-based heuristics to scan a string of code for obvious vulnerabilities (e.g., `os.system`, hardcoded secrets, `shell=True`).
4. Raise a `SecurityViolationError` if triggered.
**Acceptance Criteria:** Passing a string containing `os.system("rm -rf /")` correctly raises a `SecurityViolationError`.

### Task 2.2: Compliance Police Agent
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/execution/compliance_agent.py` (new)
**Action Steps:**
1. Create `engine/execution/compliance_agent.py`.
2. Define `CompliancePolice` class with `FN:verify_torro_standards`.
3. Scan an incoming python file string to ensure every `def ` has a docstring starting with `FN:`.
4. Scan to ensure file length is < 200 lines.
**Acceptance Criteria:** Returns `True` for compliant code and `False` with a strict diagnostic message for non-compliant code.

## Phase 3: The Coder and Tester Loop
**Token Estimate:** ~1M Tokens
**Objective:** Wire the fail-fast feedback loop.

### Task 3.1: Execution Orchestration Loop
**Token Budget:** 150k Tokens | **Time Estimate:** 5-10 Minutes
**Inputs Needed:** `engine/execution/main.py`
**Action Steps:**
1. Create `engine/execution/main.py`.
2. Define the main loop `FN:run_execution_cycle` that takes a code snippet.
3. Step 1: Call `CompliancePolice.verify_torro_standards`.
4. Step 2: Call `SecurityAgent.scan_payload`.
5. Step 3: Provision Sandbox -> Execute Code / Tests -> Destroy Sandbox.
6. Step 4: If any step fails, format a `MistakeAnalysisReport` payload and return it to the caller (mocking the return to Layer 1).
**Acceptance Criteria:** The script sequentially passes a valid code snippet through compliance, security, and sandbox execution, returning a Success struct. A failing snippet returns the Mistake Analysis payload.
